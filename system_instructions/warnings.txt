ADVANCED ALPHA GENERATION PLAYBOOK
====================================

## ABSOLUTE HARD RULES (NEVER VIOLATE — SYSTEM ENFORCED)

1. universe MUST always be TOP3000. Never change to TOP1000, TOP500, TOP200.
   Empirically validated: smaller universes reduce returns and hurt fitness.

2. decay MUST always be >= 1. Never set decay to 0.
   Empirically validated: decay=0 increases noise and destroys fitness.

3. These two rules override everything else in this playbook.

## PART 1: THE SIGNAL HIERARCHY

### Level 1 - Raw Signal (weak)
Single data field, minimal transformation. Example: rank(volume)
Problem: Overcrowded. Will fail SELF_CORRELATION.

### Level 2 - Relative Signal (better)
Compare asset against its group or historical self.
Example: group_zscore(close / ts_mean(close, 20), sector)

### Level 3 - Compound Signal (strong)
Cross two independent signals. One identifies WHAT to trade, one identifies WHEN.
Example: rank(ts_delta(volume, 5) / ts_std_dev(volume, 20)) * rank(-ts_delta(close, 20))

### Level 4 - Pipeline Signal (elite, use this structure always)
Build in 4 explicit layers:
  raw_signal = ...core predictive idea...;
  neutralized = group_neutralize(raw_signal, subindustry);
  smoothed = ts_decay_linear(neutralized, 5);
  alpha = quantile(smoothed, driver="gaussian")

Why: Each layer has one job. When a check fails, you know exactly which layer to fix.
  HIGH_TURNOVER -> edit smoothed line only
  LOW_FITNESS   -> edit alpha line only
  LOW_SHARPE    -> edit raw_signal line only
  LOW_SUB_UNIVERSE_SHARPE -> edit neutralized line only

## PART 2: FAILURE DIAGNOSIS PROTOCOL

### HIGH TURNOVER (>70%)
Root Cause: Signal changes position too fast.
Fix Priority:
  1. Increase decay setting by 2 (keep universe=TOP3000)
  2. Increase ts_decay_linear window in smoothed layer from 5 to 10
  3. Replace ts_delta(x, 1) with ts_delta(x, 5)
DO NOT: Change universe. DO NOT set decay to 0.

### LOW TURNOVER (<10%)
Root Cause: Signal too stable, positions never change.
Fix Priority:
  1. Decrease decay by 1 (minimum decay=1, never go below)
  2. Use shorter lookback windows
  3. Add a faster secondary signal
DO NOT: Set decay=0. Minimum is always 1.

### LOW FITNESS (< 1.0)
fitness = sharpe x sqrt(abs(returns) / turnover)
THREE causes. Read the turnover value before acting.

CAUSE A - No gaussian wrapper yet:
  Symptom: expression does NOT end with quantile() or zscore(rank())
  Fix: Add quantile(signal, driver="gaussian") as final line. Nothing else.

CAUSE B - Turnover too high (most common after CAUSE A fixed):
  Symptom: quantile() already applied, turnover > 0.40, fitness 0.6-0.9
  EMPIRICALLY CORRECT fix:
    action_type = change_settings
    Increase decay by 2 (e.g. decay=5 -> decay=7)
    Keep universe=TOP3000 (HARD RULE — enforced by system)
    Keep truncation unchanged
  Do NOT touch the expression. One change only per step.

CAUSE C - Turnover ok but fitness still low:
  Symptom: quantile() applied, turnover < 0.35, fitness still < 1.0
  Fix: Try zscore(rank(signal)) instead of quantile(). One swap.
  If still failing after swap: increase decay by 1.

DECISION TREE (follow exactly):
  quantile/zscore NOT in expression? -> CAUSE A. Add wrapper. Stop.
  wrapper present AND turnover > 0.40? -> CAUSE B. Increase decay by 2. Stop.
  wrapper present AND turnover 0.30-0.40? -> CAUSE B. Increase decay by 1. Stop.
  wrapper present AND turnover < 0.30? -> CAUSE C. Swap wrapper type. Stop.

### CONCENTRATED_WEIGHT
Root Cause: Too few stocks dominate the book.
Fix:
  1. Lower truncation to 0.02 or 0.01
  2. Wrap in group_rank(signal, industry)
DO NOT: Increase truncation.

### LOW_SUB_UNIVERSE_SHARPE
Root Cause: Signal works globally but not within sub-universes.
Fix:
  1. Change neutralization to INDUSTRY or SUBINDUSTRY
  2. Add group_neutralize(signal, subindustry) in neutralized layer
DO NOT: Use MARKET neutralization.

### LOW SHARPE (< 1.0)
Root Cause: Core signal has no predictive power.
Fix: Rewrite raw_signal layer only. Keep other layers intact.
Use one of the patterns from Part 3.

## PART 3: SIGNAL ARCHITECTURES (always use pipeline structure)

### Pattern A: Volatility-Normalized Momentum
raw_signal = ts_delta(close, 20) / ts_std_dev(close, 20);
neutralized = group_neutralize(raw_signal, subindustry);
smoothed = ts_decay_linear(neutralized, 5);
alpha = quantile(smoothed, driver="gaussian")

### Pattern B: Abnormal Volume + Price Reversion
raw_signal = rank(ts_zscore(volume, 5)) * rank(-ts_zscore(high, 5));
neutralized = group_neutralize(raw_signal, subindustry);
smoothed = ts_decay_linear(neutralized, 5);
alpha = quantile(smoothed, driver="gaussian")

### Pattern C: Liquidity-Adjusted Mean Reversion
raw_signal = (-1 * ts_delta(close, 5)) / (ts_std_dev(volume, 20) + 0.001);
neutralized = group_neutralize(raw_signal, subindustry);
smoothed = ts_decay_linear(neutralized, 5);
alpha = quantile(smoothed, driver="gaussian")

### Pattern D: Correlation Breakout
raw_signal = -1 * ts_delta(ts_corr(close, adv20, 20), 5);
neutralized = group_neutralize(raw_signal, subindustry);
smoothed = ts_decay_linear(neutralized, 5);
alpha = quantile(smoothed, driver="gaussian")

### Pattern E: Fundamental Value
raw_signal = group_zscore((1 / pbRatio) + (1 / peRatio), industry);
neutralized = group_neutralize(raw_signal, subindustry);
smoothed = ts_decay_linear(neutralized, 3);
alpha = quantile(smoothed, driver="gaussian")

## PART 4: SYNTAX RULES

1. Every statement ends with semicolon EXCEPT the last line
2. Final line must be a pure expression, not an assignment
3. Variable names: lowercase, letters/numbers/underscores only
4. ts_corr requires exactly 3 arguments: ts_corr(x, y, lookback)
5. group_* third argument is bare field name: group_rank(x, industry) not group_rank(x, "industry")
6. Count parentheses: opening must equal closing

## PART 5: EMPIRICALLY VALIDATED SETTINGS

universe:       TOP3000 always (HARD LOCK)
decay:          1 to 10, NEVER 0 (HARD LOCK, minimum=1)
neutralization: SUBINDUSTRY for most signals
truncation:     0.04 to 0.08
